# Hauntboard

Start with the [root README](../README.md) for the current release, local setup, contract and VPS deployment. The shipping contract is schema 4 in `template-public/`; `template/` and older localnet evidence describe historical development.

The hosted beta uses Esmeralda test currency, public immutable posts, native stealth posting fees and browser-local wallet keys. Existing manifest verification flags remain false; the explicitly enabled testnet beta profile retains the network/template checks. This is not a mainnet or fully verified production release.

See [architecture](docs/tari-l2-architecture.md), [VPS instructions](deploy/VPS.md), [wallet adapter](wallet-recovery/README.md), and [contract](template-public/RELEASE.md).

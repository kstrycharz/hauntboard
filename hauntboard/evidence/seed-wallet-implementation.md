# Seed wallet verification — October 7, 2026

The local shipping candidate now offers Create wallet and Recover with seed phrase, with no wallet file controls. Its 24-word phrase derives the same owner/view keys using released native Tari wallet crypto. Device passwords protect local encrypted storage and can differ on a fresh browser. New records authenticate their public address in metadata so the same phrase can reset a forgotten device password while refusing another identity. The format is Hauntboard BIP39, not native Tari CipherSeed.

Fresh Chromium and Firefox tests both passed creation/confirmation, native fund scanning, a real post, recovery on a fresh browser with a different password, same-address verification, encrypted posting-change quarantine, invalid-phrase rejection, refusal to overwrite another identity, and another real signed post. Test runners check that seed/password values never appear in outgoing request bodies and write no phrases to evidence. See seed-wallet-chromium.json and seed-wallet-firefox.json.

Scanning accounts for confirmed transactions appearing later in the indexer and skips only the provider's exact spent-substate response; unavailable or unverified data does not become a spendable coin. Mobile layout checks passed 320/360/390/430/768 pixels and landscape in both browsers. Chromium mobile native posting, stale-tab state, coin reservation and lost acknowledgement reconciliation passed. Legacy encrypted-record restore and account signing passed, with the internal compatibility API rather than removed file controls. Eight delivery/operational tests passed. The native recovery build script passed in the pinned Rust container. GitHub workflow changes are prepared locally; no hosted run is claimed.

The non-root application image was rebuilt as hauntboard-delivery:0.5.0 and the local preview restarted on 0.0.0.0:8283, preserving existing volumes. Wallet crypto requires HTTPS or localhost; HTTP LAN access is read-only. Public Esmeralda recovery/posting, native CipherSeed interoperability, registry publication and VPS deployment remain open gates.
